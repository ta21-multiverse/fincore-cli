# FinCore CLI

FinCore CLI is a banking application managed through a command-line interface. It allows you to deposit into and
withdraw from your account.

## Project Structure

This project follows
the [Maven Project Structure](https://maven.apache.org/guides/introduction/introduction-to-the-standard-directory-layout.html),
where source code can be found in `src/main/java`, and unit tests in `src/test`.

## Development Environment Setup

I am using the [Intellij IDEA](https://www.jetbrains.com/idea/) IDE for this project. The configuration for this IDE can
be found in the `.idea` folder. Note that user-specific configuration files have not been included.

I am using OpenJDK 25 for this project to enable access to the newest Java features provided by Java 25.

## Initial Goals for the Project

This project has been developed as part of the Java Software Engineering programme from Multiverse. It will thus grow in
functionality as I learn. My main goal for this project is to learn more about robust programming in Java, using the
most suitable data types, and working with technologies such as unit tests.
